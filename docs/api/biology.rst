biology
=======

.. currentmodule:: pyRadPlan.biology

Radiobiology: biological models (RBE and LQ formalisms) and the tissue properties they
evaluate. :mod:`pyRadPlan.biology.tissues` has no dependencies on the rest of pyRadPlan;
:mod:`pyRadPlan.biology.models` builds on machines and dose engines.
